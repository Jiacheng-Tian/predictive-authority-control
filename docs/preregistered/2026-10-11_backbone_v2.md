# Preregistration: backbone v2 (disturbance-trained supervised authority)

Branch `backbone-v2` (from followup-experiments).  Diagnosis motivating
this stage: the v3 backbone trains ONLY on structured scenarios
(oracle labels 78% high-alpha) and confidently extrapolates high alpha
OOD; the residual stack is anchored to it (deployment alpha tracks the
backbone), so the base's OOD prior caps the whole family.  User-approved
questions and answers before execution:

- Q random currents -> labels?  A: closed-loop teacher execution with the
  privileged rollout oracle per step (analytic-current families exact;
  ou/colored frozen-current approximation over the 20-step horizon,
  disclosed).
- Q noisy labels learnable?  A: S0 gate measures it before committing.
- Q why supervised?  A: oracle labels inject the missing "authority
  fails here" supervision without exploration; RL stays as the residual
  fine-tune stage on top.

## S0 outcome (passed 2026-10-11)

18 episodes / 37.8k rows (actuator train + d5/d6probe/d8probe +
random_freq train + ou train).  Gate results: episode-disjoint val
R^2 = 0.476 (>=0.30); low-alpha fraction at delay=5 = 27% (>=15%);
oracle backs off already at delay 5 (mean alpha 0.768 -> 0.652) so the
curriculum cap delay<=5 keeps unseen (6-10) disjoint.

  (load_alpha_model_checkpoint must accept without code changes).
- S3 gate: backbone-v2 as the transformer method on the formal grid

  seen within +5% of v3 (0.0635 -> <=0.0667).
- S4: residual RL (frozen protocol) retrained on backbone-v2.
- S5: 24x120 formal, unseen<=0.125 success line, comparison set
  unchanged (vs v3, constant alpha, p0t30 0.1346).
